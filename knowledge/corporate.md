# Корпоративное обучение

## Для кого

Для компаний и команд от 3 человек, которым нужен английский для работы: переписка, созвоны с иностранными коллегами и клиентами, презентации, собеседования при выходе на международный рынок.

## Форматы

- Групповые занятия для команды: группа от 3 до 8 человек одного уровня, 60 минут, два раза в неделю. Стоимость $12 за человека за занятие, минимальный пакет 16 занятий на группу.
- Индивидуальные занятия для сотрудников: по обычным индивидуальным ценам, компания оплачивает пакет для каждого сотрудника.
- Смешанный формат: групповые занятия плюс индивидуальные для руководителей.

## Как это устроено

1. Бесплатная оценка уровня всех участников: письменный тест и короткое интервью с каждым.
2. Разделение на группы по уровню и программа под задачи компании (например, лексика вашей отрасли, типовые ситуации из вашей работы).
3. Занятия в Zoom в рабочее или нерабочее время по выбору компании.
4. Ежемесячный отчёт для руководителя: посещаемость, прогресс каждого участника, рекомендации.

## Документы и оплата

Заключаем договор с компанией, выставляем счёт, оплата по безналичному расчёту. Возможна помесячная оплата. Для компаний из стран ЕС предоставляем инвойс с реквизитами для международного перевода.

## Что нужно, чтобы начать

Напишите в этот чат: сколько человек, какая сфера, какая цель обучения, желаемое время занятий. Менеджер в течение одного рабочего дня пришлёт предложение и назначит оценку уровня.
