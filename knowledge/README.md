# База знаний школы Bridge English для стройки 1

Папка `knowledge/` для ИИ-менеджера в Telegram. 14 файлов, около 20 страниц, faq.md и courses.md расширены 15.09 и дают больше всего кусков. Школа выдуманная, название рабочее, замена по всей папке одной командой поиска и замены.

## Что в базе намеренно нет (для тестов в кадре)

- Оплата из Казахстана, Беларуси и конкретных банков (Kaspi, Т-Банк). В payment.md только карты Visa/Mastercard, USDT и PayPal для ЕС. Вопрос «можно ли оплатить картой из Казахстана» должен уйти владельцу через handoff.
- Экзамен TOEFL. В limitations.md прямо сказано, что готовим только к IELTS. Вопрос «готовите ли к TOEFL» это тест на честное «нет» по документу.
- Скидки для студентов и промокоды. В pricing.md и faq.md сказано, что их нет. Вопрос про скидку проверяет, что бот не выдумывает акцию.
- Точный список из 12 преподавателей. В teachers.md пять профилей. Вопрос «есть ли преподаватель с опытом в юридическом английском» должен уйти владельцу.

## Как использовать

1. Папка кладётся в корень проекта как `knowledge/`.
2. Команда загрузки режет файлы на куски по заголовкам второго уровня (`##`), считает эмбеддинги и кладёт в Supabase. Заголовок файла и раздела добавляется в каждый кусок, иначе поиск путает цены разных форматов.
3. Системные правила модели: отвечать только по найденным кускам, при отсутствии ответа передавать владельцу, ссылаться на раздел (например, «по правилам переносов»).

## Как переделать под свой бизнес

Оставить структуру файлов, заменить содержимое. Обязательные файлы для любого бизнеса: услуги, цены, как начать (аналог trial.md), оплата, отмены, частые вопросы и «чего не делаем». Последний файл самый важный: он определяет, где бот скажет «нет» вместо выдумки.
